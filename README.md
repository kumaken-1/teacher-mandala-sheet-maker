# マンダラ・プランナー

教師が、自分の授業・校務・思考整理・企画・振り返りのために、マンダラシート（9×9）を作成・印刷・保存・再利用するためのWebアプリです。

## 使い方

- ブラウザで開いて、そのまま入力できます。
- 最初に「何のためのマンダラ？」から用途を選ぶと、まわり8マスに考える入口のヒントが入ります（あとで変更も削除もできます）。
- 右の「選択中のマス」で、本文とヒントを1マスずつ編集できます。ヒントは元番地の横に薄く表示され、本文には入りません。
- 「ガイド」はシートを見ながら使えます。用途・発想・観点から候補を選んで反映できます。
- 自動保存は、同じ端末・同じブラウザ内に保存されます。
- 正式に残す場合は「ファイル保存」でJSONファイルを保存します。
- 「テンプレート保存」で、本文を空にしてヒント・配置・色だけを残したテンプレートを保存できます。来年や別単元で使い回せます。
- 「読み込み」からJSONファイルを復元できます。テンプレート（_template.json）を選ぶと、本文は空・ヒント入りの新しいシートとして始まります。
- 「スプシにコピー」でGoogleスプレッドシートやExcelに貼り付けられます。

## 注意

- 入力したデータはGitHubへ送信されません。
- 児童名・保護者名・成績・健康情報などの個人情報は入力しない運用にしてください。
